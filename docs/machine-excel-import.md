# 机台 Excel 导入

## 操作步骤

1. 顶部选择项目，进入“机台”，点击右上角“Excel 导入机台”。需要高级工程师或管理员角色及该项目写入权限。
2. 下载机台模板。模板与当前项目绑定，不可换项目使用，不要移动表头或修改隐藏标识。
3. 从第 6 行开始，每行填写一台机台，最多 500 台。填写完成后保存为 `.xlsx`。
4. 选择文件并填写本次导入原因，点击“检查文件并预览”。此时不会创建机台。
5. 核对检查结果，再点击“确认导入机台”。资料错误必须先修正；仅有基线警告仍可导入，软件版本留空。
6. “近期导入记录”保留逐台结果、原始输入及警告。点击已导入机台名称可打开详情。部分失败可重试未完成项，成功项不会重复导入。

## 字段约定

| 字段 | 填写方式 |
| --- | --- |
| 机台序列号、机台名称、录入原因 | 必填。已有序列号（含历史删除机台）不会被覆盖；文件内也不允许重复。序列号按文本填写以保留前导零。 |
| 机型、位置、负责人、工艺、配置 | 可选。配置是文字资料，不是组件版本清单。 |
| 状态 | 下拉选择在用、短期 CIP、长期 CIP、暂未过货、已归档；空白默认在用。 |
| 预计恢复时间 | CIP 状态必填。文本格式 `YYYY-MM-DD HH:mm`，例如 `2026-10-01 09:00`，按北京时间解释。 |
| 整机阶段 | Lab、MoveIn、T0、T1、T2、T3、STR、HVM；空白默认 Lab。 |
| PM1～PM6 阶段 | 填阶段表示该腔室已安装，空白表示未安装。例如仅 PM1、PM6 有值，则只建立这两个腔室。 |
| 当前实际基线名称 | 可选。精确匹配本项目已发布基线名称（忽略大小写及首尾空白），不猜测相近名称，不匹配其他项目。 |
| 配置记录日期 | 匹配有效基线时必填，文本格式 `YYYY-MM-DD`，例如 `2026-09-20`，不晚于今天。按该日北京时间零点记录初始快照，不代表安装时间。 |

## 基线与错误处理

- 匹配成功：将基线包含的软件版本登记为初始完整实际配置，安装时间保持未知；不会给机台指派目标，也不会改变项目标准或执行安装。
- 基线为空：机台软件版本保持未录入。
- 基线无法识别、未发布、属于其他项目或没有软件项：允许机台资料导入，软件版本留空，结果中以红色警告明确展示。
- 预览后基线撤回或快照改变：不使用变化后的基线偷偷导入，改为资料导入和版本留空警告。
- 序列号冲突、名称/原因缺失、阶段错误等资料问题：不允许提交该预览，修改原表后重新上传检查。
- 多台机台按台执行，不承诺跨机台全批事务。基线配置写入失败时会明确说明机台资料已保存，并允许重试配置；不要把失败提示理解为所有机台均未创建。
- 不接受公式、宏、外部链接；请使用模板文本或下拉选项。文件限制为 10 MB。

本次不增加数据库表或 Migration，复用已有导入预览存储及业务命令。数据库仍须升级到仓库当前迁移版本；PostgreSQL 17 与 Windows Production Integration Pending 的验收边界不变。
